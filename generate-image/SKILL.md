# Generate Image

你是一个系统流水线型基础生图能力，不负责面向用户的提示词澄清，也不改写调用方提供的提示词。

最终输入契约只有 3 项：
- `prompt`
- `size`
- `files`

最终输出目标只有 1 项：
- 图片的本地文件路径

# 核心规则

- `prompt` 必须原样使用，不擅自改写、润色、扩写或拼接新语义。
- `size` 必须是合法的 `宽x高` 像素值。
- `files` 是可选参考图列表；没有参考图时允许为空数组。
- 成功生成后，必须返回生成的本地文件路径。

# 工作流

## 1. 校验输入与配置

- 校验 `prompt` 非空。
- 校验 `size` 合法：
  - 最大边长 `<= 3840`
  - 宽高都必须是 `16` 的倍数
  - 长短边比例 `<= 3:1`
  - 总像素数介于 `655360` 与 `8294400`
- 校验 `files` 中每个路径存在且是支持的图片类型。
- 收集生图所需的凭证信息（`OPENAI_BASE_URL`，`OPENAI_API_KEY`）。如果用户在本次会话中提供了可复用的凭证配置，主动询问是否要持久化到当前 skill 目录下的 `.env`，避免后续类似场景重复询问。
- 尽量通过环境变量或 skill 目录下的 `.env` 提供密钥，不要直接把密钥写进 prompt。

## 2. 执行生图

使用本技能自带 CLI 执行兜底生图。默认模型为 `gpt-image-2`。

```bash
node ./bin/generate.js \
  --prompt "<prompt>" \
  --size "1008x1792" \
  --file "/path/to/file1.png" \
  --file "/path/to/file2.jpg"
```

传参规则：
- `--prompt`：调用方提供的原始提示词
- `--size`：合法 `宽x高`
- `--file`：每张参考图传一个 `--file`
- `--model`：可选，默认 `gpt-image-2`
- 如果没有参考图，则不传 `--file`

## 3. 返回本地路径

- 生图成功后，最终只返回真实本地文件路径。

## 凭证

支持以下环境变量配置 OpenAI 接口：
- `OPENAI_BASE_URL`
- `OPENAI_API_KEY`

### 配置方式

1. **交互式弹窗（优先）**：如果工具支持交互式弹窗（如 `AskUserQuestion`），优先通过弹窗引导用户输入配置，一次性询问所有必填字段。
2. **`.env` 文件**：在当前 skill 目录下创建 `.env` 文件。
3. **环境变量**：通过 `export` 设置。

### 优先级

环境变量优先级：**已有环境变量 > `.env` 文件 > 默认值**

脚本启动时会自动读取当前 skill 目录下的 `.env`（如果存在），仅在对应环境变量**尚未设置**时作为默认值注入。

### 配置落盘

当用户在会话中首次提供配置时，一次性询问所有必填字段（Base URL、API Key、是否保存到 .env），用户确认后统一写入，写入时避免覆盖已有配置项。

# 输出要求

- 成功时只返回最终图片本地文件路径。
- 失败时直接报错，不做交互式追问。
